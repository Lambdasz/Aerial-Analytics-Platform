# Backend Commands Mapping: Module 03

This document maps all 39 Tauri IPC commands registered in `src-tauri/src/lib.rs` (lines 440–485) under the `map_controller` namespace to their Rust handlers, execution boundaries, primary instance access guards, and disk side effects.

---

## 1. Overview & Security Enforcement

Commands modifying data within `map_storage/` MUST enforce primary instance locking via `instance_lock::require_primary_instance()?`. Commands that are read-only or pure computational calculators do not require process locks.
