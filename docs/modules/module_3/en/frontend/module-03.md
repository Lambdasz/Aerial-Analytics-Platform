# Frontend Components Breakdown: Module 03

This document details the functional specifications, component interactions, and state responsibilities of the primary React components comprising **Module 03 (Aerial Image Map Explorer)**.

---

## 1. Page Container & Layout (`MapPage.tsx`)

The root page component for Module 03 is [`MapPage.tsx`](file:///d:/project/Aerial-Analytics-Platform/src/modules/module-03/pages/MapPage.tsx).

- **Role**: Coordinates the high-level layout between the interactive Leaflet map canvas and the collapsible control sidebars.
- **Child Organisms**:
  - `MapCanvas`: Full-screen Leaflet container.
  - `MapLeftPanel`: Collapsible drawer hosting the primary operational tabs (AOI, Layers, Results, Ortho).
  - `MapViewControlBar`: Floating control overlay for map manipulation (zoom, center, measurement tools).
  - `ImageGallerySidebar`: Secondary drawer for inspecting geotagged drone capture photos.
- **State Coordination**: Maintains active tab index and drawer open/closed state without forcing unnecessary re-renders of the map canvas.

---

## 2. Interactive Map Canvas & Layer Rendering

### `MapCanvas.tsx`

- **Role**: Instantiates the Leaflet `MapContainer`, sets the default center (`[-7.2575, 112.7521]` Surabaya) and zoom (16), and initializes tile layers.
- **Children**:
  - `ManagedMapLayers`: Renders all active vector and raster overlays.
  - `DrawingControlBar`: Injects Geoman controls into the map container.
  - `MeasureResultCard`: Floating measurement display when measuring distance or area.

### `ManagedMapLayers.tsx`

- **Role**: Declarative coordinator of all active Leaflet map layers.
- **Layer Types Handled**:
  - **TileLayer**: Offline or local slippy tiles generated from orthomosaics (`map_storage/images/{id}/tiles/{z}/{x}/{y}.png`).
  - **GeoJSON**: Vector layers for spatial classification results (vegetation clusters, landcover boundaries).
  - **Polygon**: Area of Interest boundary overlays with interactive selection and highlighting.
  - **Markers**: Geotagged drone photo locations and user-created spatial annotations.
- **Performance Optimization**: Uses declarative rendering rather than direct imperative DOM mutations to prevent memory leaks during rapid layer toggling.

## 3. Left Panel Navigation & Toolbars

### `MapLeftPanel.tsx`

- **Role**: Provides a clean tabbed interface using Blueprint.js `Tabs` and `Tab`:
  - **Tab 1: Area of Interest (AOI)**: Hosts `AoiToolbar` for drawing, listing, and calculating polygon metrics.
  - **Tab 2: Layers**: Hosts `LayerManager` for toggling visibility, opacity sliders, and managing annotations.
  - **Tab 3: Spatial Results**: Hosts `SpatialResultTree` for browsing detection and classification outputs.
  - **Tab 4: Orthomosaics**: Hosts `OrthoImportPanel` for uploading, inspecting, and managing GeoTIFF rasters.

### `AoiToolbar.tsx`

- **Role**: Lifecycle management of user-drawn AOI polygons.
- **Features**:
  - Integrates with Geoman via `useLeafletGeoman` to trigger drawing modes (`polygon`, `rectangle`).
  - Calculates real-time area (hectares, square meters) and perimeter using Shoelace formula and geodesic algorithms in `lib/aoiCalculations.ts`.
  - Child Molecules:
    - `AoiCreateForm`: Inline creation form for naming and styling draft polygons.
    - `AoiCardItem`: Sidebar card showing polygon name, color, area, and action buttons.
    - `AoiDetailModal`: Technical modal displaying vertex coordinates and bounds.
    - `DeleteAoiDialog`: Deletion confirmation dialog.

### `LayerManager.tsx`

- **Role**: Centralized control of map layer opacity and display hierarchy.
- **Features**:
  - Opacity sliders (0.0 to 1.0) with real-time Leaflet layer opacity updates.
  - Visibility toggles (eye icon) with functional immutable state updates.
  - Annotation management: Point, Line, and Polygon vector annotations with label tags and metadata notes.

## 4. Spatial Analysis Results & Orthomosaics

### `SpatialResultTree.tsx` & `SpatialResultDetail.tsx`

- **Role**: Browsing and inspecting spatial classification results generated by AI plugins (Module 04, Module 05).
- **Features**:
  - Hierarchical tree structure grouping results by layer, category, or confidence threshold.
  - Selection of individual features triggers map camera panning (`flyTo`) and opens property inspectors.
  - Displays classification metrics (tree count, crown diameter, NDVI vegetation health indices).

### `EditSpResultModal.tsx`

- **Role**: Comprehensive modal for editing spatial result metadata, display colors, and feature properties.
- **Key Capability (Option 2 Sync)**:
  - Supports uploading or deleting layer-level representative photos.
  - Automatically synchronizes layer image updates to all child features across `features/*.json`.
  - Provides a real-time live preview card demonstrating how feature popup cards will look on the map.

### `OrthoUploadModal.tsx` & `OrthoImportPanel.tsx`

- **Role**: Dual-mode ingestion workflow for large GeoTIFF aerial orthomosaics.
- **Dual Modes**:
  - **Mode A (Fast Copy)**: Rapid ingestion for small to medium rasters without pre-tiling.
  - **Mode B (Auto Tiling)**: Asynchronous pyramid tile generation (zoom levels 10 to 18) managed by a background worker.
- **Monitoring**: Real-time progress bar polling `.jobs/{job_id}.json` with cancellation support.
